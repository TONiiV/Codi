# Codi

Codi is one place to run and follow your coding agents.

It has two modes:

- **Telescope**: see the work. Projects, tasks, and the agents that do them, for you and your team.
- **Microscope**: do the work. Chat with an agent in one project, with diffs, files, and a terminal.

Codi uses the agents you already have: Claude Code, Codex, Cursor, Grok Build, OpenCode, Antigravity, and fx. It runs on web, desktop, and mobile.

> [!NOTE]
> Codi is early. Telescope is a prototype. Expect changes.

## Start

```bash
npx t3@latest
```
