# Start a workspace in Telescope

When you open Telescope and have no workspace yet, it walks you through three steps: create or
join a workspace (joining takes the invite code an admin sent you), mount your Code projects, and
invite a coworker. You can skip the last two and do them later from **项目** and **成员与授权**.

If you reload before finishing the second and third steps, Telescope opens as usual and you
continue from **项目** and **成员与授权**.

Only admins can mount projects and make invite codes; a member goes straight to the usual pages.
