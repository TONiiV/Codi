# Start a workspace in Telescope

When you open Telescope and have no workspace yet, it walks you through three steps.

1. **Create or join a workspace.** Create one (enterprise for a team, personal for yourself), or
   switch to joining and enter the invite code an admin sent you.
2. **Mount projects.** Every Code project that no workspace has mounted is listed. Press **接入**
   on each one you want in the workspace. Skip this step to do it later from **项目**.
3. **Invite a coworker.** Make an invite code and copy it. A code works once and expires. You can
   skip this step; skipping is remembered in this browser only.

Only admins can mount projects and make invite codes. If you are a member, the steps you cannot
do are skipped and Telescope opens as usual. To invite someone later, use **成员与授权** in the
account menu.
